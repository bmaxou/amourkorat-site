Proverbes

N'appelle pas le chat pour mettre d'accord deux oiseaux qui se battent
La nuit, tous les chats sont gris
C'est le nid d'une souris dans l'oreille d'un chat
Qui ne nourrit pas le chat nourrit le rat
Chat timide fait souris effrontée
Chat échaudé craint l'eau froide
Quand le chat est parti, les souris dansent
Chat gourmand rend la cuisinière avisée
Un chat perd ses poils, pas ses manières
Il ne faut pas réveiller le chat qui dort
Les chiens ne font pas des chats
Qui vit avec les chats prendra goût aux souris
Chat emmouflé ne prend souris
Il n'est si petit chat qui n'égratigne
Occasion trouve qui son chat bat
A vieux chat, jeune souris
Il n'y a pas de chat, si fourré soit-il, qui n'ait pas de griffes
Les mots aimables ne nourrissent pas le chat
Qui naquit chat court après les souris
